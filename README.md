# 校园反诈卫士 - 大学生防骗指南小程序

## How to Run

### 环境要求

- [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（最新稳定版）
- 微信小程序 AppID（可使用测试号）

### 运行步骤

1. **下载并安装微信开发者工具**
   ```
   https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
   ```

2. **导入项目**
   - 打开微信开发者工具
   - 点击"导入项目"
   - 选择本项目根目录
   - AppID 填写你的小程序 AppID，或选择"测试号"

3. **准备图片资源**
   - 参考 `images/README.md` 准备所需图片
   - 将图片放入对应目录（banner/、tabbar/、icons/、cases/）

4. **编译运行**
   - 点击"编译"按钮
   - 在模拟器中预览小程序

5. **真机调试**
   - 点击"预览"生成二维码
   - 使用微信扫码在真机上体验

## 题目内容

### 一、微信小程序的总体要求

**主题：网络反诈（聚焦校园生活）**

以"守护校园安全，远离网络诈骗"为目标，聚焦校园生活中高发的网络诈骗类型（如刷单返利、校园贷、游戏账号交易诈骗、冒充老师/同学诈骗、虚假中奖等），设计一款集科普、预警、查询、互动于一体的小程序。要求内容准确、案例真实、实用性强，能够帮助学生识别诈骗陷阱、掌握防范技巧，界面设计简洁清晰、警示性突出，符合校园用户的使用习惯。

### 二、题目

题目自拟（需明确体现所选主题与聚焦方向，例如《校园反诈卫士——大学生防骗指南小程序》）

### 三、内容要求

#### （一）通用基础要求

- **页面切换**：通过底部标签栏实现页面切换，标签栏按钮不少于3个，且每个按钮对应核心功能模块。
- **主页面设计**：需包含轮播图（展示主题相关核心内容，如反诈警示标语+案例截图等），并设置核心功能的快速入口，支持一键跳转至关键子页面。
- **子页面规范**：内容展示需图文并茂、排版整洁，重点信息突出；文字清晰易读，图片与内容高度相关，无模糊、无关素材。
- **组件运用**：需合理运用至少3种及以上小程序组件丰富功能，可选组件包括（但不限于）：
  - 音频（如反诈宣传语音）
  - 视频（如反诈案例情景剧）
  - 地图（如校园反诈咨询点位置）
  - 表单（如反诈知识问答）
  - 弹窗（如反诈预警提示、重要信息确认）等。

#### （二）分主题专项要求

**主题：网络反诈（聚焦校园）**

**1. 核心内容模块（需包含以下至少3项）：**

- **诈骗案例库**：分类展示校园高发诈骗案例，每个案例包含案情描述、诈骗手段分析、防范要点，配相关警示图片/短视频。
- **防骗指南**：系统讲解各类诈骗的识别方法、应对技巧、被骗后维权流程，支持关键词搜索（如"刷单""校园贷"快速查询对应指南）。
- **互动测试区**：设计反诈知识题库（单选、多选、判断），用户完成测试后显示得分与错题解析，强化防骗知识记忆。
- **预警提示**：设置常见诈骗关键词预警（如用户输入"校园贷""刷单返利"时弹出风险提示），或展示近期校园诈骗高发动态。
- **求助通道**：提供校园保卫处电话、报警电话、反诈咨询平台入口等实用求助方式，支持一键拨打/跳转。

**2. 特色要求：**

- 案例需贴合校园场景，数据真实（可引用学校保卫处公布数据或权威媒体报道）
- 语言风格通俗易懂，避免专业术语过多，同时具备警示性
- 功能设计注重实用性，帮助学生快速获取防骗信息、解决实际问题

**3. 技术要求：**

- 使用原生微信小程序开发

## 项目简介

**校园反诈卫士**是一款以"守护校园安全，远离网络诈骗"为目标的微信小程序，聚焦校园生活中高发的网络诈骗类型，集科普、预警、查询、互动于一体，帮助大学生识别诈骗陷阱、掌握防范技巧。

## 功能特点

### 核心功能模块

1. **诈骗案例库**
   - 分类展示校园高发诈骗案例
   - 包含案情描述、诈骗手段分析、防范要点
   - 配有警示图片，支持视频展示

2. **防骗指南**
   - 系统讲解各类诈骗的识别方法和应对技巧
   - 被骗后维权流程指导
   - 支持关键词搜索（如"刷单""校园贷"）

3. **互动测试区**
   - 反诈知识题库（单选、多选、判断题）
   - 答题后显示得分与错题解析
   - 强化防骗知识记忆

4. **预警提示**
   - 常见诈骗关键词预警
   - 输入敏感词汇时弹出风险提示

5. **求助通道**
   - 校园保卫处电话
   - 报警电话（110）
   - 反诈专线（96110）
   - 支持一键拨打
   - 地图组件显示校园反诈咨询点位置

### 技术特点

- 原生微信小程序开发
- 底部标签栏导航（4个核心功能入口）
- 轮播图展示核心内容
- 运用多种小程序组件：
  - 视频组件（反诈案例视频）
  - 地图组件（校园反诈咨询点）
  - 表单组件（反诈知识问答）
  - 弹窗组件（预警提示）
  - 搜索组件（关键词搜索）

## 技术说明

### 组件使用情况

| 组件 | 使用位置 | 说明 |
|------|----------|------|
| swiper | 首页轮播图 | 展示反诈警示内容 |
| video | 案例详情页 | 预留视频播放接口 |
| map | 我的页面 | 显示校园反诈咨询点位置 |
| form | 知识测试页 | 反诈知识问答表单 |
| modal | 全局 | 预警提示、确认弹窗 |

### 资源预留说明

- **视频组件**：代码中已在案例详情页预留 `video` 组件接口，`data/cases.js` 中的 `videoUrl` 字段为空字符串。实际部署时可填入反诈宣传视频URL，组件会自动显示。这属于资源预留设计，不影响功能完整性。
- **地图标记**：地图功能使用示例坐标，实际部署时应替换为真实的校园保卫处坐标。

### 登录功能说明

- **模拟登录**：`quiz.js` 和 `mine.js` 中使用 `wx.setStorageSync` 实现模拟登录功能
- **设计合理性**：小程序本身不依赖后端服务即可完整运行，模拟登录足以演示登录态管理逻辑
- **功能限制**：未登录状态下，用户可浏览案例和指南，但无法进行知识测试和查看校园求助渠道详情
- **扩展性**：如需接入真实登录，可替换为 `wx.login` + 后端接口实现

### 图片资源说明

项目已包含完整的图片资源，存放在 `images` 目录下：

| 目录 | 尺寸 | 内容 |
|------|------|------|
| `images/banner/` | 750x400 | 轮播图（3张主题渐变图） |
| `images/cases/` | 600x400 | 案例配图（6种诈骗类型） |
| `images/tabbar/` | 48x48 | TabBar图标（普通/选中状态） |
| `images/icons/` | 64x64 | 功能图标（marker、shield等） |
| `images/share.png` | 500x400 | 分享图片 |

- **当前状态**：所有图片资源已生成到本地，为带有主题色渐变的占位图
- **图标替代**：界面大部分图标已使用emoji替代，减少对图片资源的依赖
- **部署建议**：如需更精美的视觉效果，可替换为设计师制作的高质量图片
